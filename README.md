# LPIC 1 101-500 Exam Prep

> [!Warning]
> This is NOT a prepared course, this is IRL stream of me studying for the exam and taking notes accordantly.

This project is an Obsidian vault for some notes i took while preparing for the Linux Professional Institute Certificate 101-500 Exam.

I took these notes in a Twitch's IRL streams on my channel [The Novice Engineer](https://www.twitch.tv/thenoviceengineer).

## Project Content

### Linux Professional Institute
Insdie the folder _lpic-exam_ you will find the official [syllabus](https://github.com/anaskaadan98/LPIC-1-Exam-Prep/blob/main/lpic-exam/LPI-Learning-Material-101-500-en.pdf) file that we are studying from.

### Obsidian Vault
Inside vault you will see two folders _src_ for all source files and _Ink_ which containes hand drawn charts using a plugin.

The main home page for the vault is [LPIC-01 101.md](https://github.com/anaskaadan98/LPIC-1-Exam-Prep/blob/main/lpic-exam/vault/LPIC-01%20101.md) file.
